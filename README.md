## 📂 Featured Projects

### 🛒 [E-Commerce Funnel Analysis](https://github.com/arvindparaliya/e-commerce-funnel-analysis)
*Python (pandas), Tableau*
- Defined a user-level, 7-day conversion metric on **42M real e-commerce events**: **9.21%** of new viewers bought within 7 days (plausible range 9.18% to 9.25%), a lower bound because slower buyers are excluded
- Found that **41.6% of buyers never used the cart**, so a standard view → cart → purchase funnel would have overstated cart drop-off
- Ranked categories by opportunity: apparel converts at **1.74%**, with up to about **16,100 extra buyers if it matched the baseline (a scenario, not a forecast)**
- Designed a randomized size-guide test (about 46K users per group, returns as the guardrail). It is a **design only**: no experiment was run

### 🏥 [E-Commerce Funnel Analysis](https://github.com/arvindparaliya/health-care-analysis)
*SQL, Power BI*
- Analyzed 10,000+ patient records to identify treatment patterns, cost drivers, and demographic trends
- Built interactive Power BI dashboards tracking admissions, treatment costs, and patient demographics
- Found cancer to be the highest treatment cost driver and that 67.5% of admissions were urgent, a pattern that could inform hospital resource planning
